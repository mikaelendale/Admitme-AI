# 🎓 AdmitMe — MVP Launch Plan
### Features That Ship Fast & Generate Revenue

---

## 🚀 MVP Philosophy

> Ship the **three things** students will pay for immediately:  
> *Know where I stand. Know what to fix. Write my essays.*  
> Everything else is V2.

---

## ✅ MVP Feature Set (Launch-Ready)

### 1. 🧠 Smart Profile Engine *(Core Foundation)*
- **Free-form profile intake** — paste anything, AI structures it automatically
- **Profile completeness score (0–100)** — specific, actionable gaps, not a vague bar
- **GPA normalizer** — weighted/unweighted, international boards (IB, A-Levels, CBSE, etc.)
- **Spike detector** — identifies if student has a standout theme or is a generalist
- **Academic trajectory analysis** — grades trending up vs. down tells a different story

> **Why this ships first:** Without a profile, nothing else works. This is the data backbone.

---

### 2. 🗺️ College List Builder *(First Revenue Hook)*
- **Instant personalized list** — reach / target / safety in seconds
- **"Why this school" explanation** — 3–5 sentence reasoning per school
- **Fit score** — academic, interest, and financial fit, scored separately
- **Deadline tracker** — EA / ED / RD deadlines in one calendar
- **List balancer** — warns if list is too reach-heavy or safety-heavy
- **Financial aid estimator** — rough net cost based on family income

> **Why this drives revenue:** This is the #1 thing students need and will pay for immediately.

---

### 3. ⚡ Gap + Fix Engine *(The Killer Feature — Core Differentiator)*
- **Rejection risk analysis** — top 3 rejection reasons per school, in plain English
- **Gap scoring** — Critical / Moderate / Minor, ranked by priority
- **Fix roadmap** — step-by-step action plan per gap (specific programs, timelines, not vague advice)
- **Timeline-aware advice** — junior vs. senior in October gets completely different guidance
- **What-if simulator** — "If I raise my SAT 100 points, how does my list change?"

> **Why this is the moat:** Nothing like this exists. This is the feature that earns word-of-mouth.

---

### 4. ✍️ Essay Suite *(Highest Willingness to Pay)*
- **Essay brainstormer** — 10–15 profile-specific Common App angles (not generic prompts)
- **Draft assistant** — AI writing partner that preserves the student's voice
- **Essay roast** — brutally honest critique: structure, clichés, voice, emotional impact
- **Cliché detector** — flags overused stories and phrases
- **"Why This School" generator** — first draft for every school on the list
- **Supplemental essay manager** — all school-specific essays tracked in one place
- **Essay strength score** — rated on Authenticity, Specificity, Impact, Structure, Differentiation

> **Why this monetizes fast:** Students and parents will pay $50–$100/month just for this module alone.

---

### 5. 🤖 AI Mentor — Conversational Layer *(Retention + Engagement)*
- **Always-on chat** — profile-aware, never generic answers
- **Honest, calibrated responses** — not cheerleading. If a school is a long shot, it says so
- **Proactive nudges** — "You haven't touched your Stanford supplement in 3 weeks"
- **Tone settings** — Brutally Honest / Balanced / Encouraging

> **Why this retains users:** Students come back daily because it feels like a real advisor.

## 🚫 Cut from MVP (Ship in V2)

| Feature | Why It Waits |
|---------|--------------|
| Parent Dashboard | Nice-to-have; adds complexity, not revenue |
| Counselor Dashboard | B2B sales cycle is slow; focus on B2C first |
| International Student Mode | Expand after core market is proven |
| Outcome Database | Needs time + data to build |
| Streak/Badge Gamification | Polish feature, not a launch blocker |
| Calendar sync (Google/Apple) | Easy to add in V2 |
| Interview Prep | Lower urgency vs. essays |
| Mood check-in | V2 wellness layer |
